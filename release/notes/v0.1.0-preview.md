# OpenLancer v0.1.0 (preview)

This is the first public build of OpenLancer, a mod editor for Freelancer (2003). It is a preview for modders who want to try the editor and report problems.

**You need your own copy of Freelancer.** This release contains no game files. At the first start, the editor asks for your game folder. It reads the files in that folder and does not change them.

## Files

- `OpenLancer-v0.1.0-preview-win-x64.zip`: the editor, the Play runtime and `oltool` for Windows 10 and 11, 64-bit. You do not need to install .NET.
- `OpenLancer-v0.1.0-preview-win-x64.zip.sha256`: the SHA-256 hash of the zip.
- `openal-soft-1.25.2.tar.gz`: the source code of OpenAL Soft. The zip contains OpenAL Soft as the compiled file `x64\soft_oal.dll`, under the GNU LGPL version 2.

To check the zip, run `Get-FileHash .\OpenLancer-v0.1.0-preview-win-x64.zip` in PowerShell. The hash must be the same as the hash in the `.sha256` file.

## Start

Extract the zip and read `README-FIRST.txt`. Then start `OpenLancer.Editor.exe`. The preview has no digital signature, so Windows can show a SmartScreen warning. On Windows 11, Smart App Control can block the preview.

## What is in this preview

- A game link: the editor reads your game folder and shows the game and its version. It identifies Freelancer 1.0 and 1.1, with or without JFLP, and Freelancer: HD Edition.
- A first start that makes a profile and an empty mod for you.
- A 3D Scene of each star system, with a Hierarchy, an Inspector and a Database of ships, equipment, bases and factions.
- Edits with lists of valid values, color pickers, snap and undo. Move, rotate and zone size in the Scene.
- Mods that hold only your changes. Before a save, the editor checks the mod. When it finds a value that stops or crashes the game, it stops the save and tells you why. It does not find all such values.
- Play: a test run of your mod with F5 from the Scene camera, and a reload of the running game at each save.
- A cutscene editor: browse and preview the cutscenes of the game, and change their values in a mod.
- `oltool` to check a game folder, and to validate, merge and inspect mods.

## Known limits

- No export to the original game or to HD Edition yet. You can test a mod only with Play of the editor.
- Play is a test run of the editor, not a release of a game. It runs the OpenLancer runtime, a fork of the Librelancer engine, not the original game program. It does not play the whole story, and some missions, AI behaviors, effects and cutscenes differ from the original.
- We tested only the data of the English version 1.0. The editor detects version 1.1 and HD Edition, but we did not test them.
- OpenLancer does not support total conversions such as Discovery.
- The mod format can change before version 1.0.
- Windows only.

## Report a problem

Open an issue at https://github.com/spool1/openlancer/issues. Give the version, the game and the version that the editor shows, the steps, and the log files. The log files show the paths of your folders, which can contain your Windows user name. Do not attach game files. Do not report OpenLancer problems to the Librelancer project.
