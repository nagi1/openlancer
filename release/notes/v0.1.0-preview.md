# OpenLancer v0.1.0 (preview)

This is the first public build of OpenLancer, a mod editor for Freelancer (2003). It works with Freelancer 1.1, Freelancer: HD Edition 0.7.1 and Freelancer-Decomp source builds. It is a preview for modders who want to try the editor and report problems.

**You need your own copy of Freelancer.** This release contains no game files. At the first start, the editor asks for your game folder. It reads the files in that folder and does not change them.

## Files

- `OpenLancer-v0.1.0-preview-win-x64.zip`: the editor, the Play runtime and `oltool` for Windows 10 and 11, 64-bit. You do not need to install .NET.
- `OpenLancer-v0.1.0-preview-win-x64.zip.sha256`: the SHA-256 hash of the zip.
- `openal-soft-1.25.2.tar.gz`: the source code of OpenAL Soft. The zip contains OpenAL Soft as the compiled file `x64\soft_oal.dll`, under the GNU LGPL version 2.

To check the zip, run `Get-FileHash .\OpenLancer-v0.1.0-preview-win-x64.zip` in PowerShell. The hash must be the same as the hash in the `.sha256` file.

## Start

Extract the zip and read `README-FIRST.txt`. Then start `OpenLancer.Editor.exe`. The preview has no digital signature, so Windows can show a SmartScreen warning. On Windows 11, Smart App Control can block the preview.

## Supported games

| Game | Edit and check mods | Export (drop-in zip and FLMM package) | Play the mod in the game (Ctrl+F5) |
|---|---|---|---|
| Freelancer 1.1 (retail) | Yes | Yes | Yes |
| Freelancer: HD Edition 0.7.1 | Yes | Yes | Yes |
| Freelancer 1.0 (retail) | Yes. It has the same INI files as 1.1. | Yes, for 1.1 | Patch the game to 1.1 first. The 1.0 program does not start on Windows 10 and 11. |
| A source build of the Freelancer-Decomp project that you build yourself | Yes, with its INI files of 1.1 | Yes, for 1.1 | Yes, with **Play > Play in source build** |

F5 plays the mod in the OpenLancer engine with the data of any linked game. Exports hold only the changes of your mod, and they never write into a game folder. OpenLancer contains no code of the Freelancer-Decomp project.

## What is in this preview

**Game link and profiles**
- A first start that links your game folder, makes a profile and an empty mod, and opens it.
- A Game link window that shows each linked game, its version and the result of its check. It identifies Freelancer 1.0 and 1.1 (with or without JFLP), HD Edition and a Freelancer-Decomp source build.

**Scene and data editors**
- A 3D Scene of each star system, with a Hierarchy, an Inspector and a Database of ships, equipment, bases, goods and factions.
- Edits with named fields, lists of valid values, color pickers, snap and undo. Move, rotate and zone size in the Scene.
- Create, duplicate, rename and delete for objects, zones and lights, as in Unity. A delete fixes or marks the references to the item.
- An Assets panel with images of the game and mod assets. Drag an asset into the Scene. Prop groups that you place again in any system.
- Picks of nebulae and asteroid fields. Markets with named fields and a "Buys or sells" choice.

**Missions**
- A mission studio: a browser of the 14 story missions, a mission graph, a mission layer in the Scene, and mission pages in the Inspector.
- Mission editing: link triggers in the graph, insert a delay, add actions from a library, pick values in the Scene, and edit the raw INI with checks while you type.
- Behavior prefabs, for example "Spawn wave", with prefab mode, variants and Unity-style overrides (violet marks, Revert, Apply to prefab).
- A dry run: step through the trigger rules of a mission without the game, and go back one step at a time.

**Cutscenes**
- A cutscene editor that browses and previews the cutscenes of the game in groups: main story by mission, intro scenes, bases and rooms, bar conversations and more.
- Space cutscenes show the star system of their mission behind them.

**Export, publish and play**
- Export of a mod for Freelancer 1.1 and HD Edition 0.7.1 as a drop-in zip and as a Freelancer Mod Manager (FLMM) package, with a Nexus page text and a checklist.
- A Mods window: the display name, version, description, changelog and screenshots of each mod, previews of the Nexus page and the FLMM entry, a publish checklist and an export history.
- Play in the game (Ctrl+F5): the editor installs the mod into a play copy of the linked game and starts it. Your game folder does not change.
- Play in OpenLancer (F5), with a reload of the running game at each save.

**Console and checks**
- The Console hides the messages of problems that the game data itself has. It always shows the problems that your mod causes.
- Before a save, the editor checks the mod. When it finds a value that stops or crashes the game, it stops the save and tells you why.

**Agents (MCP)**
- An MCP server for AI agents, for example Claude Code: query tools and image tools of the Scene and the cutscene preview. It is read-only in this preview. It accepts connections only from this computer. See `docs/MCP.md` in the source.

**Tools**
- `oltool` checks a game folder, and validates, merges, exports and inspects mods.

## Known limits

- Play in OpenLancer (F5) runs our fork of the Librelancer engine, not the original game program. Some missions, AI behaviors, effects and cutscenes differ from the original game. Use Ctrl+F5 to test a mod in the real game.
- You cannot start a mission at a chosen trigger yet. The MCP server cannot edit yet.
- You cannot create jump gates, jump holes, trade lane rings, new bases, nebulae or asteroid fields yet. You can select only one item at a time.
- The newest parts (the mission studio, the Mods window and the MCP server) were tested mostly with automatic tests.
- OpenLancer does not support total conversions such as Discovery.
- The mod format can change before version 1.0.
- Windows only.

## Report a problem

Open an issue at https://github.com/spool1/openlancer/issues. Give the version, the game and the version that the editor shows, the steps, and the log files. The log files show the paths of your folders, which can contain your Windows user name. Do not attach game files. Do not report OpenLancer problems to the Librelancer project.
